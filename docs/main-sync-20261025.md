## 小米盒子特供版的身份

本节保留升级前 73 版的比较快照。后续已完成主线功能移植及 79 版实机验证，最新结果和可复用经验见[小米盒子 Android 6 适配记录](mibox-android6-lessons-20261025.md)。该独立本地归档按收尾约定在经验文档推送后清理；以下路径只标识历史材料，不是持续可用的下载或恢复位置。

比较对象是独立归档 `Live-MiBox-Special-20261022` 明确标注的已安装固定 APK：

`workspace-snapshot/artifacts/mibox-api23-20261021/live-gecko-bf51cf0cdd00.apk`

其 SHA-256 经本地重新计算为 `bf51cf0cdd00e03b82f0608026d43c1227db6f0052d20af56b7339aa5a526300`，大小 121,779,995 字节。归档的 `docs/android6-home-mode.md` 记录了完整 Live 的重新安装、CCTV-13 音画确认，以及 CCTV-14 / CCTV-12 切台结果。

归档基线为 `404048b`，但源码快照含后续并行修改，不能当作这个 APK 的精确构建输入。以下结论优先依据固定 APK 的 Manifest、DEX 类和资源；盒子设备未在本轮连接，也未被升级。

| 方面 | 小米盒子已安装特供包 | 当前主线及 Redmi 安装包 |
| --- | --- | --- |
| 系统适配 | minSdk 23，面向 Android 6；含旧系统兼容层 | minSdk 26，面向 Android 8 及以上 |
| 包身份 | `com.live.tv`，`1.0.0-rc1` / 73，Debug | `com.live.tv`，`1.0.0-rc1-recovery3` / 73，Debug |
| 央视播放内核 | 内置 ARMv7 Gecko；含 `GeckoCctvBackend` | 系统 WebView 与自有 MSE 播放路径；不含 Gecko |
| ABI 与体积 | 仅 ARMv7，约 121.78 MB | ARMv7 + ARM64，约 59.03 MB |
| 流媒体浏览 | 已有影视点播、缓存、音乐和 Web 控制基础；不含新的原生资源库 | 遥控器海报墙、提前预加载、失效海报补齐、在线播放/缓存选集与删除管理 |
| 影视来源 | 原 MacCMS 路径，不含 `WsyzyProvider` | 增加无损云联想搜索、50 条上限、重复分页处理 |
| 直播操作 | 频道侧栏，确认键等进入菜单 | 确认键播放/暂停、横向频道条，与点播统一视觉 |
| 导航与桌面 | 原有频道/工具界面，`HomeMode` / `HomeTools` 与 `LiveHome` 入口 | “直播 / 流媒体 / 设置”文字侧栏、统一播放控件、可选 `DesktopHome` 桌面入口 |
| 设置工具 | 应用列表、网络、蓝牙、系统设置及恢复桌面 | 桌面开关、默认桌面选择及系统设置；未搬入旧版完整工具页 |
| 浏览期间直播 | 不含本轮原生浏览页与后台静音保留逻辑 | 浏览流媒体、详情和设置时静音保留，返回恢复声音并保留手动暂停 |
| 恢复与路由 | 不含主线的 `LivePlaybackRecovery` / `CctvWebViewRouting` 类 | 包含独立停顿恢复和 CCTV 路由处理 |

盒子 APK 与当前主线的 `cctv-adapter.js` 内容完全相同，NAL 后处理修复是共享能力，不能算作主线独有改进。当前主线的 minSdk 26 不满足该 Android 6 盒子的安装条件；如需把新界面迁移到盒子，需要在独立兼容版里保留 Gecko 和 API 23 适配后再验证，不能直接覆盖安装当前主线 APK。

两个包均通过签名检查，使用同一个 Android Debug 证书；两个桌面入口在 APK 中均默认关闭。盒子旧版已经有短暂 HOME 暂停/恢复处理，本轮主线增加的是原生浏览页之间保持直播的完整路径，不能将旧版描述为完全没有生命周期恢复。

历史设备记录中的 CleanYourTV 默认桌面接管、原小米桌面移除和系统精简，不属于特供 APK 的默认功能，也不随本次 Git 推送改变。后续在单独授权的设备操作中，Live 79 已成为唯一可用桌面；本地归档的清理边界见上述适配记录。
