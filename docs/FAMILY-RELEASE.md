# 家庭自用 APK

当前范围：仅本人及家人直接安装 APK，不上架、不创建公开发布。当前主线候选为 `1.0.0-rc1-recovery3` / 73，最低 Android 8.0（API 26），保留 ARMv7 / ARM64 双架构，尚非正式 1.0。

当前 Redmi 使用包含原生流媒体、缓存选集、桌面设置和浏览时静音保留直播功能的双架构 **Debug 开发包**。2026-10-25 已重新读取电视安装包哈希，与当前主线构建完全一致；见 [主线同步记录](main-sync-20261025.md)。下文 Release 签名流程与 10 月 22 日及更早的设备记录继续保留，但不代表当前安装包为 Release 构建。

## 签名与升级

用户已选择沿用当前本机签名密钥。已安装电视 0.6.63/72 与本机 debug 证书 SHA-256 一致：

`912fbb81d051b3e1d8b3a7b975ae477bc03f8dd4060220ea2fef27811fd88b65`

此证书身份为 Android Debug，但候选采用 Release 构建并关闭调试。适用于本次家庭自用升级，不作为公开发行密钥方案。私钥丢失或被其他文件覆盖会导致后续 APK 无法直接覆盖安装，应由用户安全备份原密钥；不要提交仓库、邮件公开或复制到 APK。当前不自动复制密钥。

构建读取四个环境变量：`LIVE_KEYSTORE`（绝对路径）、`LIVE_KEY_ALIAS`、`LIVE_STORE_PASSWORD`、`LIVE_KEY_PASSWORD`。全部提供才配置签名；部分提供直接失败；全部省略则允许生成未签名开发检查包。密码不写入命令记录或仓库；请在本地安全环境设置。

```sh
./gradlew :app:assembleRelease :app:lintRelease :app:testDebugUnitTest
python3 scripts/verify_release.py app/build/outputs/apk/release/app-release.apk \
  --build-tools "$ANDROID_HOME/build-tools/36.0.0" \
  --version 1.0.0-rc1-recovery3 --minimum-code 73 \
  --certificate 912fbb81d051b3e1d8b3a7b975ae477bc03f8dd4060220ea2fef27811fd88b65
```

检查脚本验证包名、版本、非调试状态、禁用备份、签名、ARM ABI、Mihomo 通知和实验/密钥资产缺失，并输出 APK SHA-256。该检查不代表真机体验合格，也不承诺不同设备均兼容。

## 安装与验收

安装前核对目标设备已安装包签名及版本。不卸载现有应用；取得设备安装授权后使用覆盖安装。签名不匹配时停止，不能以卸载绕过，否则会丢失应用数据。

真机检查沿用 [1.0 清单](RELEASE-1.0.md)。首轮重点：应用数据保留、HTTPS 证书保留、播放器标题与进度、选集焦点、搜索详情、缓存继续播放。通过候选验收后才切换正式版本号与制作最终 APK。

家庭使用不自动授予第三方素材或依赖的再分发权利。仍保留全部现有第三方通知；若将来改为公开发布，另行完成整体许可证、第三方依赖通知和源码交付审查。
